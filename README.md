# E-Commerce Customer Churn Analysis 🚀

## Project Overview
An end-to-end data analysis project investigating customer churn patterns for a subscription-based platform. This project utilizes advanced SQL queries for behavioral extraction and Python (Pandas, Seaborn, Matplotlib) for exploratory data analysis (EDA) to uncover high-risk customer segments.

## Tech Stack
* **SQL (MySQL Workbench):** Advanced aggregations, grouping, CTEs, and window functions (`RANK()`).
* **Python:** Pandas, Matplotlib, Seaborn.

## Key Insights & Findings
1. **Contract Type Impact:** Month-to-month customers exhibit a significantly higher churn rate compared to those on 1-year or 2-year contracts.
2. **Monthly Charges Correlation:** Customers with higher monthly charges show an increased tendency to churn, highlighting price sensitivity or value misalignment.

## Repository Structure
* `sql_queries.sql` — SQL scripts used to extract and analyze customer behavior.
* `churn_analysis.ipynb` — Jupyter Notebook containing data cleaning, manipulation, and visual reports.
